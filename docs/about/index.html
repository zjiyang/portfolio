Artist Statement

Every few days I start a new sketch. I write it, run it, change a number, and watch what happens on screen. These sketches began as recreations and practice, with no fixed theme.

For me, making visual work is how writing code stays joyful. That joy is rare, and I want to hold on to it. I care about what an image tells people, and how a small change makes them feel. That is where a line of code comes alive.

What I want to see is often very subtle. To get there, I need to truly understand what each line of code does, so I can change the small details that matter to me.

About this site

Sketches is where I practise. Each one stays as it was that day, a record of what I was learning.

Works are not sketches picked out and made a little bigger. A work fills the whole screen and becomes part of the site itself. You can drag it, type into it, click it, or save it. Each work grows out of a few days of sketches, and the dates under it take you back to the day it began.
